# Multi-Step Form

A responsive multi-step form application built with Angular and TypeScript.

## Features

* Multi-step form navigation
* Personal information form
* Plan and billing selection
* Add-ons selection
* Order summary
* Form validation
* Responsive design for different screen sizes

## Technologies

* Angular
* TypeScript
* HTML
* CSS

## Purpose

This project was built to practice Angular Signals, routing, form handling, state management, validation, and responsive web design.
